# My Todo App

# Description:

This app was created to be a todo list to create a list of tasks to be done.It was created in React.

# Installation: make sure you have node.js installed.

Put in `npx create-vite@latest --template react .` into the terminal and press Enter.
Then you type `npm install` into the terminal and press Enter.

# How to rungit

Put in `http://localhost:5173/` in browser search bar at the top to run the server.
